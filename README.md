# Dual-use · Windows 双模网络测速与分流延迟诊断终端

一款专为中国大陆与跨境网络环境设计的 **Windows 桌面端双通道测速与分流诊断软件**。支持**不走 VPN（纯净直连）**与**走 VPN（代理隧道）**两种测速模式，涵盖上下行带宽检测、中国大陆常用软件延迟矩阵、海外常用软件延迟矩阵，以及智能分流健康度诊断。

## 核心功能亮点

1. **双模式切换与同屏对比（不走 VPN vs 走 VPN）**
   - **不走 VPN · 纯净直连 (`DIRECT`)**：底层通过 `httpx.Client(trust_env=False)` 与直连 Socket 强制绕过 Windows 系统代理设置，直接通过物理网卡测量运营商原始宽带速度与国内应用直连延迟。
   - **走 VPN · 代理隧道 (`PROXY / TUN`)**：支持自动读取 Windows 系统代理，或一键选择 Clash (`127.0.0.1:7890`)、v2rayN (`127.0.0.1:10809`)、Sing-box (`TUN 虚拟网卡`)，精确测量代理隧道加密传输下的真实带宽损耗与海外访问延迟。
   - **双模连续对比 (`DUAL DIFF`)**：一键先跑直连、再跑 VPN，自动计算**下行带宽保持率 (%)**、**中国大陆软件分流保速差值 (ms)** 与 **海外软件连通率**。

2. **上传与下载速度检测（60fps 动态流体曲线）**
   - 多线程并发流式下载与上传压测，支持 `Mbps` 与 `MB/s` 单位一键切换。
   - 实时计算基准延迟 (Ping)、网络抖动 (Jitter)、丢包率与抗缓冲膨胀评级 (Bufferbloat A+ ~ C)。

3. **中国大陆常用软件 vs 海外常用软件延迟测试**
   - **中国大陆常用软件（5 项核心 + 自定义扩展）**：微信 (WeChat)、哔哩哔哩 (Bilibili)、抖音 (Douyin)、淘宝/阿里云 CDN、百度搜索。
   - **海外常用软件（5 项核心 + 自定义扩展）**：Google 搜索/套件、YouTube (4K/8K)、ChatGPT / OpenAI、GitHub、Telegram。
   - 支持按分类筛选（社交与办公 / 影音与流媒体 / 开发与 AI / 游戏平台）、单节点独立重测，以及**添加自定义软件或域名**。

4. **极简高雅的双主题桌面 UI**
   - 默认采用**浅色高雅磨砂（Alabaster Frosted）**视觉风格，支持一键切换**深色曜石（Obsidian Dark）**主题。

## 在 Windows 上运行与打包指南

### 方式一：一键启动原生桌面端（推荐）
双击运行目录中的 `run_desktop.bat`：
- 脚本会自动检测 Python 环境并在首次启动时通过清华镜像源安装 `pywebview` 与 `httpx[socks]`，随后启动无边框风格的 Windows 原生桌面客户端。
- 若电脑未安装 Python，也可直接双击 `netpulse_speedtest.html` 在 Edge / Chrome 中即刻使用。

### 方式二：一键打包为独立 `.exe` 可执行文件
双击运行目录中的 `build_exe.bat`：
- 自动调用 `PyInstaller` 将前端与 Python 双栈测速引擎封装为单文件 `dist\Dual-use_SpeedTest.exe`，无需目标机器配置环境即可分发运行。
